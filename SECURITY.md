# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private **Report a vulnerability** form in the repository's Security tab. If that form is unavailable, contact the repository owner privately with:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the affected version or commit.

You will get an acknowledgement within a few days. Please give us a reasonable amount of time to release a fix before disclosure.

## Supported versions

Only the latest release receives security fixes.

## Scope

The threat model is documented in [docs/security.md](docs/security.md). Behaviour listed under *Known limitations* there is not a vulnerability, unless you find a way around a stated control.
